# pgx

`pgx` opens an instrumented connection pool for PostgreSQL on top of
[jackc/pgx v5](https://github.com/jackc/pgx). It returns a plain
`*pgxpool.Pool`, so you can use jackc/pgx directly, generate code with sqlc,
or wrap the same pool in gorm with `pgx/gorm`. It is the canonical Postgres
package (D7 in [`docs/decisions.md`](../docs/decisions.md)). Do not call
`pgxpool.New` or `gorm.Open` yourself.

Both packages are named `pgx`. In a file that uses both, import jackc/pgx
as `jpgx`; kitchen code and every snippet below do the same:

```go
import (
	jpgx "github.com/jackc/pgx/v5"

	"github.com/dungnh3/kitchen/pgx"
)
```

## Install

```bash
go get github.com/dungnh3/kitchen          # package pgx (core module)
go get github.com/dungnh3/kitchen/pgx/gorm  # package pgxgorm, only if you use gorm
```

## Quick start

```go
ctx := context.Background()
pool, err := pgx.Open(ctx, pgx.Config{
	URL:             os.Getenv("DATABASE_URL"),
	MaxConns:        50,
	ApplicationName: "orders",
	// Behind PgBouncer in transaction mode:
	// QueryExecMode: pgx.ExecModeExec,
}, pgx.WithLogger(log.Default()))
if err != nil {
	return
}
defer pool.Close()

var n int
_ = pool.QueryRow(ctx, "SELECT count(*) FROM orders").Scan(&n)
```

`Open` parses the config, adds tracing and metrics, connects and pings. On
error, no pool is left open. You own the pool and must `Close` it.

What the defaults give you:

- **TLS is required.** `SSLMode` defaults to `require`. A URL without
  `sslmode` also gets `require`, so pgx never uses libpq's `prefer`, which
  silently falls back to plaintext. `PGSSLMODE` in the environment still wins.
- **A URL is the whole config.** With `URL`, only `User`, `Password` and
  `Database` may override it. `Host`, `Port` or `SSLMode` next to a URL is an
  error, so the TLS server name and fallback hosts cannot drift from the URL.
- **Fail fast.** `Open` pings within `ConnectTimeout` (5s) and returns an
  error. It never calls `log.Fatal`.
- **No time zone.** `pgx` sets none. Set `RuntimeParams["timezone"]` yourself
  (services generated by `zen new service` use `UTC`).
- **No SQL in telemetry.** Spans carry no statement text or values.

## Configuration

All fields live in `pgx.Config`. Zero values mean the default.

| Field | Default | When to change it |
|---|---|---|
| `URL` | none | `postgres://` URL or key=value DSN. Use it, or `Host` + `Database`. |
| `Host`, `Port` | none, `5432` | When you do not use a URL. Port is range-checked. |
| `User`, `Password`, `Database` | none | Credentials; override the URL's. The password is escaped for you. |
| `SSLMode` | `require` | `verify-full` to check the server certificate. `disable` only for local servers. |
| `MaxConns` | pgx: `max(4, NumCPU)` | Size it to your load and the server's `max_connections`. |
| `MinConns` | `0` | Keep warm connections for latency-sensitive services. |
| `MaxConnLifetime` (+ `Jitter`) | `30m` (+ `5m`) | Shorter behind load balancers that drop long connections. |
| `MaxConnIdleTime` | `5m` | Lower to release idle connections faster. |
| `HealthCheckPeriod` | `30s` | Rarely. |
| `ConnectTimeout` | `5s` | Slow networks. It also bounds the ping in `Open`. |
| `StatementTimeout` | server default | Cap runaway queries per session. |
| `ApplicationName` | none | Always: it shows in `pg_stat_activity`. |
| `RuntimeParams` | none | Session parameters, such as `{"timezone": "UTC"}`. |
| `QueryExecMode` | `ExecModeCacheStatement` | `ExecModeExec` or `ExecModeSimpleProtocol` behind PgBouncer in transaction mode. |

Options: `WithLogger`, `WithTracerProvider`, `WithMeterProvider` (default:
the OTel globals) and `WithoutPoolStats`. See the
[godoc](https://pkg.go.dev/github.com/dungnh3/kitchen/pgx) for details.

Fields instead of a URL:

```go
ctx := context.Background()
pool, err := pgx.Open(ctx, pgx.Config{
	Host:     "db.internal",
	User:     "orders",
	Password: os.Getenv("PG_PASSWORD"),
	Database: "orders",
	SSLMode:  "verify-full", // also checks the server certificate and host name
})
if err != nil {
	return
}
defer pool.Close()
```

### A local server without TLS

TLS is on by default because database traffic carries credentials and
customer data. A local Docker Postgres usually has no TLS, so `Open` fails
until you turn it off explicitly. **Never ship this setting:** with
`disable`, credentials and data travel in plaintext.

```go
ctx := context.Background()
pool, err := pgx.Open(ctx, pgx.Config{
	Host:     "localhost",
	User:     "app",
	Password: os.Getenv("PG_PASSWORD"),
	Database: "app",
	SSLMode:  "disable", // or ?sslmode=disable inside a URL
})
if err != nil {
	return
}
defer pool.Close()
```

## Integration with kitchen

A service `main` sets up the logger once, opens one pool, and adds the pool's
`Ping` as a readiness check:

```go
ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
defer stop()

opts, _ := log.OptionsFromEnv()
logger, _ := log.Setup(opts)

pool, err := pgx.Open(ctx, pgx.Config{
	URL:             os.Getenv("DATABASE_URL"),
	ApplicationName: "orders",
	RuntimeParams:   map[string]string{"timezone": "UTC"},
}, pgx.WithLogger(logger))
if err != nil {
	logger.ErrorContext(ctx, "postgres", log.Err(err))
	return
}
defer pool.Close()

srv, err := server.New(
	server.WithLogger(logger),
	server.WithServices( /* services that take pool */ ),
	server.WithReadiness(server.Check{Name: "postgres", Func: pool.Ping}),
)
if err != nil {
	logger.ErrorContext(ctx, "server", log.Err(err))
	return
}
if err := srv.Run(ctx); err != nil {
	logger.ErrorContext(ctx, "server", log.Err(err))
}
```

The full service wiring (errors, auth, admin port, shutdown) is in
[`../server/USAGE.md`](../server/USAGE.md).

- **Logger.** `WithLogger` takes a `*log.Logger`. nil means `log.Default()`,
  the logger `main` installed with `log.Setup`.
- **Readiness.** Use `pool.Ping` as the `server.Check` func. There is no
  `pgx.Ping`. `server` caches results for one second and bounds each run to
  5s, so probes do not load the database. A worker without a gRPC server
  uses `server.NewAdmin(addr, server.WithAdminChecks(...))` instead.
- **Telemetry.** `pgx` uses the global OTel providers by default. Install
  them with `otelx/sdk.Setup` in `main` before `pgx.Open`. Pass
  `WithTracerProvider`/`WithMeterProvider` only to use other providers.
  Query spans are children of the request span when you pass the request
  `ctx`.
- **Migrations.** `migrate.NewPostgres(pool, ...)` runs goose migrations on
  the same pool and never closes it.

### Errors: MapError

`MapError` turns pgx and Postgres errors into `errs` sentinels. Call it once,
at the repository edge. Handlers then return the error unchanged, and
`server` renders the right gRPC/HTTP status.

```go
err := pgx.MapError(fmt.Errorf("get order 42: %w", jpgx.ErrNoRows))
fmt.Println(errors.Is(err, errs.ErrNotFound))
fmt.Println(errs.Code(err))
// Output:
// true
// NotFound
```

| Postgres error | errs sentinel |
|---|---|
| `jpgx.ErrNoRows` | `ErrNotFound` |
| 23505 unique, 23P01 exclusion | `ErrAlreadyExists` |
| other class 23 (foreign key, check, not null) | `ErrFailedPrecondition` |
| class 22 (data exception) | `ErrInvalidArgument` |
| 40001 serialization, 40P01 deadlock | `ErrAborted` (retry the transaction) |
| 57014 query canceled (statement timeout) | `ErrDeadlineExceeded` |
| class 08, 53300, 57P01–57P03 | `ErrUnavailable` |

The original error stays as the cause, for logs and `errors.Is/As`. Clients
see only the sentinel's generic message, so table, column and constraint
names never leak. `nil`, errors that are already `*errs.Error`, context
errors and unmapped codes come back unchanged.

## Advanced

### sqlc

Generate with `sql_package: "pgx/v5"`. `*pgxpool.Pool` and `jpgx.Tx` both
satisfy the generated `DBTX`, so pass the pool to `New` and a transaction to
`WithTx`. The types below stand in for sqlc's generated code.

```go
// DBTX is the interface sqlc generates for sql_package "pgx/v5".
// *pgxpool.Pool and jpgx.Tx both satisfy it.
type DBTX interface {
	Exec(ctx context.Context, sql string, args ...any) (pgconn.CommandTag, error)
	Query(ctx context.Context, sql string, args ...any) (jpgx.Rows, error)
	QueryRow(ctx context.Context, sql string, args ...any) jpgx.Row
}

// Queries stands in for sqlc's generated type (db.New(pool), q.WithTx(tx)).
type Queries struct{ db DBTX }

func New(db DBTX) *Queries { return &Queries{db: db} }

func (q *Queries) WithTx(tx jpgx.Tx) *Queries { return &Queries{db: tx} }

func (q *Queries) MarkPaid(ctx context.Context, id int64) error {
	_, err := q.db.Exec(ctx, "UPDATE orders SET paid = true WHERE id = $1", id)
	return err
}
```

```go
ctx := context.Background()
pool, err := pgx.Open(ctx, pgx.Config{URL: os.Getenv("DATABASE_URL")})
if err != nil {
	return
}
defer pool.Close()

q := New(pool)
err = jpgx.BeginFunc(ctx, pool, func(tx jpgx.Tx) error {
	return q.WithTx(tx).MarkPaid(ctx, 42)
})
if err = pgx.MapError(err); errors.Is(err, errs.ErrAborted) {
	// serialization failure or deadlock: retry the transaction
	return
}
```

### pgx hooks: ParseConfig and OpenConfig

Use this when you need `AfterConnect`, custom type registration or other
pgx hooks. `ParseConfig` applies the same defaults as `Open`; `OpenConfig`
adds instrumentation (unless a tracer is already set), connects and pings.

```go
ctx := context.Background()
pc, err := pgx.ParseConfig(pgx.Config{
	URL:              os.Getenv("DATABASE_URL"),
	StatementTimeout: 10 * time.Second,
})
if err != nil {
	return
}
pc.AfterConnect = func(ctx context.Context, c *jpgx.Conn) error {
	_, err := c.Exec(ctx, "SET search_path TO orders, public")
	return err
}
pool, err := pgx.OpenConfig(ctx, pc)
if err != nil {
	return
}
defer pool.Close()
```

### Many short-lived pools

Open one pool per database per process. The pool statistics are OTel
callbacks that live as long as the MeterProvider; they are never
unregistered. Per-tenant pools, or code that opens and closes pools
repeatedly, should skip them (or use a dedicated MeterProvider):

```go
ctx := context.Background()
pool, err := pgx.Open(ctx, pgx.Config{URL: os.Getenv("TENANT_DATABASE_URL")},
	pgx.WithoutPoolStats())
if err != nil {
	return
}
defer pool.Close()
```

### PgBouncer

The default `ExecModeCacheStatement` prepares statements per connection. It
breaks behind PgBouncer in transaction mode. Set `QueryExecMode:
pgx.ExecModeExec`, or `pgx.ExecModeSimpleProtocol` for any pooler.

## Backends and adapters

### pgx/gorm (package pgxgorm)

`pgxgorm.Open` builds a `*gorm.DB` on top of a pool from `pgx.Open`. gorm and
pgx share one pool: one set of connections, one `MaxConns` to tune. The
pool's otelpgx tracer traces gorm queries too, so do not add a gorm tracing
plugin. Never open a second pool for gorm.

```go
ctx := context.Background()
pool, err := pgx.Open(ctx, pgx.Config{URL: os.Getenv("DATABASE_URL")})
if err != nil {
	return
}
defer pool.Close() // pgxgorm never closes the pool

db, err := pgxgorm.Open(pool, pgxgorm.Options{Log: &gormlog.Config{
	Logger:               log.Default(),
	SlowThreshold:        500 * time.Millisecond,
	IgnoreRecordNotFound: true,
}})
if err != nil {
	return
}
var count int64
db.WithContext(ctx).Table("orders").Count(&count)
```

- **Logging** goes through `log/gormlog`. `Options.Log == nil` means errors
  and queries slower than 200ms go to `log.Default()`, with
  `IgnoreRecordNotFound` on. SQL is logged without parameter values;
  `gormlog.Config.LogParams` turns values on. Keep it off in production:
  values can hold personal data and secrets.
- **Config.** `Options.Config` is the base `*gorm.Config`. Its `Logger`, when
  set, wins over `Options.Log`.
- **Closing.** Closing the gorm `*sql.DB` does not close the pool. Close the
  pool yourself.
- **Errors.** `pgxgorm.MapError` is `pgx.MapError` plus
  `gorm.ErrRecordNotFound` → `errs.ErrNotFound`:

```go
err := pgxgorm.MapError(fmt.Errorf("first order: %w", gorm.ErrRecordNotFound))
fmt.Println(errors.Is(err, errs.ErrNotFound))
// Output: true
```

## Testing

- `MapError` needs no database: build a `*pgconn.PgError{Code: "23505"}` and
  assert with `errors.Is(err, errs.ErrAlreadyExists)` or `errs.Code(err)`.
- `ParseConfig` needs no database either. Use it to test your config
  mapping (TLS mode, runtime parameters, pool sizes).
- Integration tests in `pgx` and `pgx/gorm` start `postgres:18-alpine` with
  testcontainers-go. They skip with `-short`, with `KITCHEN_SKIP_DOCKER` set,
  or when Docker is unavailable. The container has no TLS, so tests use
  `sslmode=disable`; that is test-only.
- Tests that open many pools should pass `WithoutPoolStats`, and
  `pgx.WithLogger(log.Discard())` to keep output quiet.
- Packages use `goleak.VerifyTestMain`. Close every pool you open.

## Observability

- **Spans** (otelpgx): one per query, batch, copy, prepare and connect, with
  `db.system.name=postgresql`, `db.namespace` and `db.operation.name`. The
  SQL text is never recorded.
- **Metrics** (otelpgx): `db.client.operation.duration` and
  `db.client.operation.errors`, plus pool statistics such as
  `pgxpool.acquired_connections`, `pgxpool.idle_connections`,
  `pgxpool.max_connections`, `pgxpool.acquire_duration` and
  `pgxpool.empty_acquire_wait_time` (unless `WithoutPoolStats`).
- **Logs:** one INFO record `pgx: connected` with `host`, `database` and
  `max_conns`. `Open` errors start with `pgx:`; ping errors name
  `host:port/database`, never the password.
- **errs reasons:** see the `MapError` table above.

## Production checklist

- Keep `SSLMode` at `require`, or use `verify-full` with the server CA. Never
  ship `disable`.
- Read the URL or password from the environment or a secret store; never
  commit them.
- Set `ApplicationName`, `MaxConns` and, usually, `StatementTimeout`.
- Set the session time zone explicitly with `RuntimeParams`.
- Open one pool per database per process; share it with gorm and `migrate`.
- Add `server.Check{Name: "postgres", Func: pool.Ping}` to readiness.
- Call `MapError` at the repository edge; never return raw pgx errors.
- Behind PgBouncer in transaction mode, set `QueryExecMode`.
- Leave `gormlog.Config.LogParams` off.

## Migrating from the old kitchen

The old `storage` package (`config.Postgres` + `gorm.Open`) becomes `pgx.Open`
plus `pgxgorm.Open`; TLS is now required by default. See
[`docs/migration/data-utils.md`](../docs/migration/data-utils.md).
